# 磁盘存储

## 磁盘空间分配

| 用户类别 | `home` 磁盘配额 |
|----------|-----------------|
| 博士生 | 512 GiB |
| 其他 | 256 GiB |

可通过邮件向管理员申请额外磁盘空间，管理员将根据项目理由与资源可用情况进行评估。

如需存放大型数据集，请联系管理员。数据集托管不计入您的配额。

## 数据完整性

数据完整性**不作保证**。用户必须定期备份，建议每周备份一次，关键数据建议更高频率备份。`/shared/hdd` 与 `/shared/ssd` 目录采用 RAIDZ2，可容忍最多两块硬盘故障。RAIDZ2 **不是备份**，也无法防止所有形式的数据丢失。这些共享目录目前没有按用户设置的配额，请合理使用。

!!! info "重要"
    备份责任由用户承担。请始终为关键工作保留可恢复的检查点。

## 隐私

管理员可能收集并查看必要的访问、安全、审计、系统及资源使用日志与指标，用于运维、安全、容量规划、事件响应与策略执行。在调查事件、异常资源使用、安全问题或疑似违规行为时，管理员也可能查看文件。使用本服务器即表示用户同意上述监控与审查。

**请勿**存放私人或敏感文件（例如个人照片、视频、机密文档）。

## 磁盘使用统计

磁盘使用量按月统计（GB/月），覆盖所有服务器，并按用户分别归属。使用量较高的用户可能会被联系，要求减少磁盘占用。
