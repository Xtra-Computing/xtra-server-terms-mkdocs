# Methodology

我们如何管理 Xtra Computing 服务器，以及各项规则背后的理由。

## 为什么部署探针

服务器由越来越多的用户共享。有些任务会长时间占用 GPU、内存或 CPU，而不顾及其他用户；在共享机器上，一个这样的任务就可能让其他所有人都无法工作。

我们在每台服务器上部署了监控探针，按用户记录资源使用情况，用于：

- 了解谁在使用哪些资源，保证分配公平；
- 服务器变慢或不可用时，快速定位问题来源；
- 依据记录的数据，一致地执行[使用条款](terms.md)中的规则，包括[自动终止政策](terms.md#自动终止政策)。

收集哪些数据以及如何使用，详见[隐私](disk.md#隐私)。

## 为什么使用 Apptainer

自 2026-09-30 起，普通用户默认不再拥有 Docker 权限，容器改用 [Apptainer](apptainer.md) 运行。原因有两点：

- **安全。** `docker` 用户组权限实际上等同于主机 root。Apptainer 以你自己的用户身份运行容器，没有守护进程，也不需要加入任何等同于 root 的用户组。
- **资源统计。** Docker 中的负载无法被按用户的内存与 GPU 统计看到，过去已多次出现单个用户借此把整台服务器拖垮的情况。Apptainer 中的负载和你运行的其他进程一样，都能被正常统计。

迁移方法详见[容器：Docker 停用与 Apptainer 迁移](apptainer.md)。
